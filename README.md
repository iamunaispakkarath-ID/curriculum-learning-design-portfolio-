This version intentionally focuses on curriculum and education work; it does not include a separate Islamic Sciences section.

## Publish using GitHub Pages
1. Download and unzip this folder.
2. Upload the **contents** of this folder to the root of your GitHub repository. `index.html` must be directly at the top level, not inside a second nested folder.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment. GitHub will show the published site URL on the Pages settings screen.

## Before publishing
In `index.html`, replace `YOUR-EMAIL@example.com` in the `mailto:` link with your email address. Review the descriptions and add public links to actual project samples if you want visitors to view or download them. Do not upload confidential student or school information.
